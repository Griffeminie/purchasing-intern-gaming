# purchasing-intern-gaming
Local web tool for PO scanning, Excel verification, and purchasing data visualization — built for office use over WiFi. basically streamlining monitoring process

Things to install to setup:
1. Node.js
Download from nodejs.org — lets you run a local server so the app is accessible on the office WiFi
2. VS Code Extensions
Live Server — for quick testing during development
Prettier — code formatting

PURCHASING MONITORING SYSTEM - SETUP GUIDE

Requirements:
- Node.js (v18+ recommended)

First Time Setup:
1. Open a terminal in the project folder.
2. Install dependencies:

   npm install

3. Make sure the Excel file exists:

   data/monitoring.xlsx

4. Start the server:

   node server.js

5. Open the browser and go to:

   http://localhost:3000

Access from Phone (Optional):
1. Install ngrok. login and add your auth key
2. Run:

   ngrok http 3000

3. Open the HTTPS link generated by ngrok on your phone.

Project Structure:
- public/          -> Frontend files (HTML, CSS, JS)
- data/            -> Excel database
- server.js        -> Backend server
- uploads/         -> Uploaded PO images

Notes:
- Do not delete monitoring.xlsx.
- Run "npm install" after pulling new changes.
- If OCR scanning does not work, ensure all npm packages are installed.
- Default port is 3000.
