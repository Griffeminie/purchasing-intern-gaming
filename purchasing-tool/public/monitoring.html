📂 Auto-Scan PO Folder

Point to the folder that contains your PO PDFs.
The system will read each filename, extract the PO number, match it to a row in the database, and link the file automatically.

Example filenames it can read:
✓ CCI - PO#400085166 PRICOM.pdf  →  matches PO 400085166
✓ CCI - PO#1000021077 RB SHINRAI.pdf  →  matches PO 1000021077
✗ Invoice_March.pdf  →  no PO number found, skipped
Paste the full path to your PO folder. Files are linked directly from that folder — nothing is copied, so there's only ever one copy on disk. If a file gets moved, renamed, or deleted from that folder later, the link will break.
